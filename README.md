# OPC OS

**An AI-native operating system for One-Person Companies.**

OPC OS is an open-source business operating system designed for entrepreneurs who run companies with minimal organizational overhead.

Instead of replacing ERP, project management, document, communication, and accounting systems, OPC OS connects them into a unified **Business Intelligence & Control Layer**.

It continuously observes business events, builds a structured view of the company's current context, uses AI to identify risks, changes, cash issues, and commitments, and turns them into actionable decisions.

The system separates **AI-generated proposals from real-world execution** through explicit policies, human approvals, idempotent actions, and complete evidence and audit trails.

The core operating loop is:

**Observe → Understand → Identify → Decide → Act → Verify → Remember**

OPC OS is built around a domain-driven architecture where the core business concepts are **Issue, Commitment, Proposal, Decision, Approval, Action, and Evidence**.

The long-term goal is simple:

> **Give one person the operating leverage of an organization.**
